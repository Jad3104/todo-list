# To-Do List

A simple To-Do List web application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using localStorage
- Load saved tasks automatically
- Add tasks using the Enter key

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## What I Learned

- DOM manipulation
- Event handling
- Working with arrays and objects
- Data persistence using localStorage
- Separating structure, styling, and behavior
